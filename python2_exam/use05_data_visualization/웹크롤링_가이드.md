# 웹크롤링 기초 가이드

## requests와 BeautifulSoup 사용법

이 가이드는 Python의 `requests`와 `BeautifulSoup` 라이브러리를 사용하여 웹크롤링하는 방법을 단계별로 설명합니다.

---

## 2단계: 기본 개념 이해

### requests란?

- 웹 페이지에 HTTP 요청을 보내고 HTML 데이터를 받아오는 라이브러리
- 웹 브라우저가 하는 일을 Python 코드로 수행

### BeautifulSoup란?

- HTML/XML 문서를 파싱(분석)하여 원하는 데이터를 쉽게 추출하는 라이브러리
- HTML 구조를 탐색하고 특정 요소를 찾는 도구

---

## 3단계: 로컬 HTML 파일로 연습하기

실제 웹사이트를 크롤링하기 전에 로컬 HTML 파일(`sample.html`)로 연습해봅시다.

### 예제 1: HTML 파일 읽고 파싱하기

```python
from bs4 import BeautifulSoup

# HTML 파일 읽기
with open('sample.html', 'r', encoding='utf-8') as file:
    html_content = file.read()

# BeautifulSoup 객체 생성
soup = BeautifulSoup(html_content, 'html.parser')

# 전체 HTML 출력 (예쁘게 정리된 형태)
print(soup.prettify())
```

**설명:**

- `open()`: 파일을 읽기 모드로 엽니다
- `BeautifulSoup(html_content, 'html.parser')`: HTML을 파싱 가능한 객체로 변환
- `prettify()`: HTML을 보기 좋게 정리하여 출력

---

### 예제 2: 특정 태그 찾기

```python
from bs4 import BeautifulSoup

with open('sample.html', 'r', encoding='utf-8') as file:
    html_content = file.read()

soup = BeautifulSoup(html_content, 'html.parser')

# 첫 번째 h1 태그 찾기
h1_tag = soup.find('h1')
print("제목:", h1_tag.text)

# 첫 번째 도서 제목 찾기
first_title = soup.find('h2', class_='title')
print("첫 번째 책:", first_title.text)
```

**설명:**

- `find()`: 조건에 맞는 첫 번째 요소를 찾습니다
- `class_='title'`: CSS 클래스로 요소를 찾습니다 (class는 Python 예약어이므로 class\_ 사용)
- `.text`: 태그 안의 텍스트만 추출

---

### 예제 3: 여러 개의 요소 찾기

```python
from bs4 import BeautifulSoup

with open('sample.html', 'r', encoding='utf-8') as file:
    html_content = file.read()

soup = BeautifulSoup(html_content, 'html.parser')

# 모든 도서 정보 찾기
books = soup.find_all('div', class_='book')

print(f"총 {len(books)}권의 책이 있습니다.\n")

for book in books:
    title = book.find('h2', class_='title').text
    author = book.find('p', class_='author').text
    price = book.find('p', class_='price').text
    rating = book.find('p', class_='rating').text

    print(f"제목: {title}")
    print(f"{author}")
    print(f"{price}")
    print(f"{rating}")
    print("-" * 40)
```

**설명:**

- `find_all()`: 조건에 맞는 모든 요소를 리스트로 반환
- `for` 루프로 각 도서 정보를 순회하며 데이터 추출

---

### 예제 4: ID로 특정 요소 찾기

```python
from bs4 import BeautifulSoup

with open('sample.html', 'r', encoding='utf-8') as file:
    html_content = file.read()

soup = BeautifulSoup(html_content, 'html.parser')

# ID로 특정 도서 찾기
book2 = soup.find('div', id='book2')

if book2:
    title = book2.find('h2', class_='title').text
    print(f"두 번째 책: {title}")
```

**설명:**

- `id='book2'`: HTML의 id 속성으로 요소를 찾습니다
- id는 페이지에서 고유한 값이므로 특정 요소를 정확히 찾을 때 유용

## 4단계: 실제 웹사이트 크롤링하기

이제 `requests`를 사용하여 실제 웹사이트에서 데이터를 가져와봅시다.

### 예제 5: 웹페이지 가져오기

```python
import requests
from bs4 import BeautifulSoup

# 웹페이지 요청
url = 'https://example.com'
response = requests.get(url)

# 응답 상태 확인
print(f"상태 코드: {response.status_code}")  # 200이면 성공

# HTML 파싱
soup = BeautifulSoup(response.text, 'html.parser')

# 제목 추출
title = soup.find('h1')
if title:
    print(f"페이지 제목: {title.text}")
```

**설명:**

- `requests.get(url)`: 웹페이지에 GET 요청을 보냅니다
- `response.status_code`: HTTP 상태 코드 (200 = 성공, 404 = 페이지 없음 등)
- `response.text`: 응답받은 HTML 텍스트

---

### 예제 6: 에러 처리하기

```python
import requests
from bs4 import BeautifulSoup

url = 'https://example.com'

try:
    response = requests.get(url, timeout=10)
    response.raise_for_status()  # 에러 발생 시 예외 발생

    soup = BeautifulSoup(response.text, 'html.parser')
    # 데이터 추출 작업...

except requests.exceptions.RequestException as e:
    print(f"요청 중 오류 발생: {e}")
```

**설명:**

- `timeout=10`: 10초 이내에 응답이 없으면 타임아웃
- `raise_for_status()`: 4xx, 5xx 에러 발생 시 예외를 발생시킵니다
- `try-except`: 에러를 안전하게 처리

## 5단계: 데이터 저장하기

크롤링한 데이터를 파일로 저장하는 방법입니다.

### 예제 7: CSV 파일로 저장

```python
import csv
from bs4 import BeautifulSoup

with open('sample.html', 'r', encoding='utf-8') as file:
    html_content = file.read()

soup = BeautifulSoup(html_content, 'html.parser')
books = soup.find_all('div', class_='book')

# CSV 파일로 저장
with open('books.csv', 'w', encoding='utf-8', newline='') as csvfile:
    writer = csv.writer(csvfile)
    writer.writerow(['제목', '저자', '가격', '평점'])  # 헤더

    for book in books:
        title = book.find('h2', class_='title').text
        author = book.find('p', class_='author').text.replace('저자: ', '')
        price = book.find('p', class_='price').text.replace('가격: ', '')
        rating = book.find('p', class_='rating').text.replace('평점: ', '')

        writer.writerow([title, author, price, rating])

print("books.csv 파일이 생성되었습니다!")
```

## 6단계: 유용한 BeautifulSoup 메서드

### 자주 사용하는 메서드

```python
# 1. find() - 첫 번째 요소 찾기
element = soup.find('div', class_='book')

# 2. find_all() - 모든 요소 찾기
elements = soup.find_all('p')

# 3. select() - CSS 선택자 사용
elements = soup.select('.book .title')  # class가 book인 요소 안의 title

# 4. select_one() - CSS 선택자로 첫 번째 요소 찾기
element = soup.select_one('#book1')

# 5. get() - 속성 값 가져오기
link = soup.find('a')
if link:
    href = link.get('href')  # 또는 link['href']

# 6. text - 텍스트만 추출
text = element.text

# 7. get_text() - 텍스트 추출 (옵션 가능)
text = element.get_text(strip=True)  # 앞뒤 공백 제거
```
