# server.py 아키텍처 및 동작 원리

## 1. 아키텍처 개요

`server.py`는 다중 클라이언트 채팅 서버를 구현합니다. 주요 구성 요소는 다음과 같습니다.

- **소켓 (socket):** 네트워크 통신을 위한 기본 인터페이스입니다. 서버 소켓은 클라이언트의 연결을 수신하고, 클라이언트 소켓은 개별 클라이언트와의 통신을 담당합니다.
- **쓰레드 (threading):** 다중 클라이언트 지원을 위해 쓰레드를 사용합니다. 각 클라이언트 연결은 별도의 쓰레드에서 처리됩니다.
- **락 (threading.Lock):** 공유 자원 (클라이언트 목록, 클라이언트 정보)에 대한 동시 접근을 제어하여 쓰레드 안전성을 확보합니다.
- **서버 실행 상태 플래그 (server_running):** 서버의 실행/종료 상태를 제어하는 플래그입니다.

## 2. 동작 원리

1.  **서버 시작 (`start_server` 함수):**
    - 서버 소켓을 생성하고, 주소와 포트에 바인딩합니다.
    - 최대 클라이언트 수를 설정하고, 클라이언트 연결을 수신 대기합니다.
    - `server_running` 플래그가 True인 동안 클라이언트 연결을 계속 수락합니다.
    - 클라이언트 연결이 수락되면, 해당 클라이언트를 처리하기 위한 새 쓰레드를 생성하고 시작합니다 (`handle_client` 함수).
2.  **클라이언트 처리 (`handle_client` 함수):**
    - 클라이언트 소켓을 클라이언트 목록에 추가하고, 클라이언트 정보를 저장합니다.
    - 클라이언트에게 입장 메시지를 브로드캐스트합니다.
    - 클라이언트로부터 메시지를 수신하고, 다른 클라이언트들에게 브로드캐스트합니다.
    - 클라이언트 연결이 종료되면, 클라이언트 소켓을 닫고, 클라이언트 목록에서 제거합니다.
3.  **메시지 브로드캐스트 (`broadcast` 함수):**
    - 특정 클라이언트 (발신자)를 제외한 모든 클라이언트에게 메시지를 전송합니다.
    - 락을 사용하여 쓰레드 안전성을 확보합니다.
4.  **클라이언트 제거 (`remove_client` 함수):**
    - 클라이언트 소켓을 목록에서 제거하고, 연결을 종료합니다.
    - 락을 사용하여 쓰레드 안전성을 확보합니다.
    - 클라이언트에게 퇴장 메시지를 브로드캐스트합니다.
5.  **서버 종료 (`shutdown_server` 함수):**
    - `server_running` 플래그를 False로 설정하여 서버 종료를 시작합니다.
    - 모든 클라이언트에게 종료 메시지를 브로드캐스트합니다.
    - 모든 클라이언트 소켓을 닫습니다.
    - 서버 소켓을 닫습니다.
6.  **예외 처리:**
    - `try...except...finally` 블록을 사용하여 다양한 예외 (연결 오류, 소켓 오류, 일반 예외)를 처리합니다.
    - `finally` 블록에서 항상 서버 종료 절차를 실행하여 자원을 해제합니다.
7.  **쓰레드 안전성:**
    - `threading.Lock`을 사용하여 공유 자원 (클라이언트 목록, 클라이언트 정보)에 대한 동시 접근을 제어합니다.
    - `with lock:` 구문을 사용하여 락을 획득하고 해제합니다.

## 3. 주요 함수 설명

- `broadcast(message_bytes, sender_socket=None)`: 메시지를 모든 클라이언트에게 브로드캐스트합니다.
- `remove_client(client_socket)`: 클라이언트 연결을 해제하고 관련 정보를 제거합니다.
- `handle_client(client_socket, address)`: 개별 클라이언트와의 연결을 처리합니다.
- `shutdown_server(server_socket)`: 서버를 안전하게 종료합니다.
- `start_server()`: 서버를 시작하고 클라이언트 연결을 수락합니다.

## 4. 개선된 종료 로직

- `server_running` 플래그를 사용하여 서버의 실행/종료 상태를 제어합니다.
- `shutdown_server` 함수를 추가하여 서버를 안전하게 종료합니다.
- `socket.settimeout`을 사용하여 `accept` 함수에서 무한정 대기하는 것을 방지하고, 주기적으로 `server_running` 플래그를 확인합니다.
- `try...except...finally` 블록을 사용하여 예외 발생 시에도 서버 종료 절차를 실행합니다.

## 5. 추가 고려 사항

- **오류 처리:** 더 자세한 오류 메시지를 제공하고, 오류 로깅을 추가할 수 있습니다.
- **보안:** 클라이언트 인증 및 데이터 암호화를 통해 보안을 강화할 수 있습니다.
- **확장성:** 더 많은 클라이언트를 지원하기 위해 비동기 I/O (예: `asyncio`)를 사용할 수 있습니다.
